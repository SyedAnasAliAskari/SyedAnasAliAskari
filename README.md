# About

### Full Stack Developer & Product Builder

I build **web applications, APIs, business platforms, and product experiences** from idea to deployment.

My work usually sits where **clean UX**, **practical engineering**, and **real-world delivery** meet. I’m comfortable working across the whole product lifecycle: shaping an idea, building the interface, developing backend systems, connecting APIs and databases, deploying the product, and refining it after launch.
